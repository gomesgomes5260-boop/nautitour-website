## Como abrir

Veja [`../README.md`](../README.md) — 3 opções (VS Code Live Preview, file://, http.server).

**Atalho VS Code:**
1. Botão direito em `01-fase1-personas.html`
2. "Open with Live Preview" (se tiver a extensão)

**Atalho terminal:**
```bash
cd design/research && python3 -m http.server 8765
# abre http://localhost:8765
```
