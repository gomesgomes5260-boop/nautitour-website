# Inspirações

Banco de referência visual. Cole prints aqui conforme você vê coisas bonitas/úteis no dia a dia. Não tem regra — quanto mais, melhor. Depois a gente cura junto.

## Subpastas

- **framework/** — Sistemas de design inteiros. Linear, Stripe, Vercel, Airbnb, Notion. Aqui mora a referência de "como um produto bem feito se comporta". Útil pra direção geral.
- **home/** — Páginas iniciais. Foco em hero, primeira dobra, hierarquia de informação. Bom pegar exemplos do nosso nicho (turismo) E fora dele (pra fugir do padrão).
- **checkout/** — Fluxos de pagamento. Quanto mais simples e claro, melhor. Cole tanto bons quanto ruins (pra a gente saber o que evitar).
- **components/** — Botões, cards, modais, inputs, toasts, badges, calendários, date pickers. Granular. Útil quando estiver desenhando a peça específica.
- **icons/** — Estilos: outline, filled, duotone, ilustrativo. Decidir o estilo agora evita inconsistência depois.
- **typography/** — Combinações de fonte. Especialmente pairs display+text. Hierarquia (h1 vs h2 vs body).
- **colors/** — Paletas inteiras. Inclusive de fora do nicho — vermelho+azul pode ser amarelo+verde se for a paleta certa.
- **mobile/** — Especificamente mobile. Bottom sheets, gestos, navegação por tabs. 50%+ do nosso tráfego é mobile.
- **tours-competitors/** — Concorrência direta + benchmarks aspiracionais. Buscaape, GetYourGuide, Civitatis, Airbnb Experiences, sites de operadoras locais.

## Tags úteis (no nome do arquivo)

Pra facilitar busca depois, segue padrão:
```
{empresa}-{elemento}-{detalhe}.png

Exemplos:
airbnb-experiences-hero-2024.png
linear-button-secondary.png
stripe-checkout-mobile.png
nautitour-CONCORRENTE-XYZ-home.png   ← se for concorrente nosso real
```

## Anotações por pasta

Se quiser explicar por que cada print te chamou atenção, cria `notes.md` na subpasta:

```markdown
# notes — framework

- linear-typography-2024.png — pairing display+text que respira bem. Acho que combina com a paleta marítima
- vercel-hero-2025.png — gradiente sutil no fundo que não distrai. Quero algo parecido mas em tons de areia/mar
- stripe-pricing-table.png — clareza visual de preço por tier — útil pra distinguir escuna vs lancha
```

Não é obrigatório. Print sem nota já vale muito.
