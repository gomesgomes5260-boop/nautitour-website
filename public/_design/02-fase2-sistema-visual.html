Paleta, tipografia & tokens

Identidade visual proposta pra Nautitour. 5 famílias de cor inspiradas no mar de Maragogi, par Fraunces + Inter, escala consistente de espaçamento e radius. Tudo conversível pra @theme do Tailwind v4.

Por que warm grays (Areia) e não cool grays? Cinzas frios (Tailwind slate ou zinc) puxam pro tecnológico/corporate. Cinzas warm (stone-like) puxam pro humano/orgânico — combinam com o mood "operador local que conhece o mar". Diferença sutil mas importante.

2Tipografia

7Tailwind v4 @theme

Snippet pronto pra colar em src/app/globals.css. Tailwind v4 é CSS-first — não precisa tailwind.config.ts.

/* src/app/globals.css */

@theme {
  /* === Tipografia === */
  --font-display: "Fraunces", Georgia, serif;
  --font-sans: "Inter", -apple-system, BlinkMacSystemFont, sans-serif;

  /* === Cores brand === */
  /* Azul-mar (primary) */
  --color-mar-50:  #E6F3FA;
  --color-mar-100: #CCE6F5;
  --color-mar-200: #99CDEB;
  --color-mar-300: #66B4E1;
  --color-mar-400: #339BD7;

  --color-mar-600: #085C8F;

Adicionar Fraunces + Inter

// src/app/layout.tsx
import { Inter, Fraunces } from "next/font/google";

const inter = Inter({
  subsets: ["latin"],
  variable: "--font-sans",
});

const fraunces = Fraunces({
  subsets: ["latin"],
  variable: "--font-display",
  weight: ["400", "500", "600", "700"],
});

export default function RootLayout({ children }) {
  return (
    <html lang="pt-BR" className={`${inter.variable} ${fraunces.variable}`}>
      <body>{children}</body>
    </html>
  );
}
